# MOMO 共通素材

複数のアプリから共通で使う素材（音・絵など）を置くフォルダです。
プログラムは `lib/` に置くので、こちらには**素材だけ**を入れます。

各アプリからは相対パスで指します。アプリはどれも `games/○○/` `tools/○○/` の深さにあるので、
書き方はどのアプリでも同じ（`../../assets/...`）になります。

## BGM `bgm/`

**曲の性格ごとにフォルダを分けます。** アプリはフォルダ名で選ぶので、
同じ性格の曲を足したいときは**そのフォルダにファイルを置くだけ**です。

| フォルダ | 中身 |
|---|---|
| `lobby/` | 対局前（トップ・ロビー・待機）。全アプリ共通 |
| `game-japanese/` | 対局中・和風 |
| `game-western/` | 対局中・洋風。Billiards と Darts が使う |
| `game-koikoi/` | 花札こいこい専用 |
| `fireworks/` | MOMO Fireworks の「音楽の花火」専用（曲に合わせて花火を上げる）。作者本人が Mureka・SUNO で作った曲 |

### 曲を増やすとき

1. 曲を軽くしてから（1曲 1〜2 MB 目安・`CLAUDE.md` §6）該当フォルダに置く
2. `node assets/make-manifest.mjs` を走らせる
3. 公開する

**プログラムは触りません。** 各アプリは `bgm/manifest.json`（目録）を読んでプールを組み立てます。
目録が要るのは、GitHub Pages がフォルダの中身を一覧で返さないためです。
フォルダを増やしたときも道具が拾いますが、そのフォルダを鳴らすアプリ側の指定は 1 行必要です。

### 権利について

ここに置く BGM は**すべて作者本人が権利を持つもの**です。
出所の不明な曲・再配布条件のある曲を混ぜないでください（クレジット表示の義務が発生し、
どのアプリがどの曲を鳴らすかを追えなくなります）。

## 効果音 `se/`

**フォルダ分けはしません。ファイル名で一意に参照します。**
複数のアプリが同じ音を使うので、名前が衝突しないように付けてください
（`se-koikoi.mp3` のようにアプリ固有の音でも、名前が一意なら同じ場所に置きます）。

効果音はバリエーション展開をしないので、目録はありません。

## 声 `voice/`

人の声の読み上げ。**用途ごとのフォルダの下に言語ごとのフォルダ**を置き、どの言語でも同じファイル名にします。
アプリは「言語のフォルダが無ければ日本語の声で鳴らす」作りにしてあるので、言語を足すときは
**そのフォルダに同じ名前のファイルをそろえて置き、アプリ側の言語の一覧に 1 つ足す**だけです。

| フォルダ | 中身 | 使うアプリ |
|---|---|---|
| `byoyomi/ja/` `byoyomi/en/` `byoyomi/zh/` | 将棋の秒読み（`sec30` `sec20` `sec10` `sec5` `n4` `n3` `n2` `n1` `timeup`） | MOMO Shogi |

### 作り方と権利について

- `byoyomi/` は **Windows の音声合成**（日本語 Ayumi・英語 Zira・中国語 Yaoyao）で 2026-10-04 に作った合成音声です。
  前後の無音を切って MP3 32kbps モノラル 16kHz に変換（道具は `L:\momo\claude\shogi-voice\`・公開しない）。
- Windows に入っている声で作った音は配ってよいとされています（Microsoft Q&A の回答。規約本文は未確認）。
  **表記の義務は見つかっていませんが、念のため使うアプリのクレジットに 1 行書きます**（将棋は設定 → クレジット）。
- 声を作り直すときは同じ道具で、同じファイル名で上書きします（履歴に古い声が残るので、作り直しは最小限に）。
