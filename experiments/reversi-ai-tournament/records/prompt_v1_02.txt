# 依頼
質問なし。提案なし。一回のプロンプトで結果(html)を出力してください。
これはAIが作ったリバーシ（オセロ）プログラムの強さを競う実験です。
あなたの持てる力をすべて使い、できるだけ強いリバーシプログラムを作ってください。
完成したプログラムは、別のAIが作ったプログラムと、共有ファイルに書く棋譜を介して自動で対戦します。
１回のチャットで完成できないと想定される場合は、複数回のチャットに分けて作業し、最終的に１本のhtmlとして完成させること。
その場合はチャットのリレー方式で組み上げていき、次のチャットへの引継ぎファイルを出力して次につなげること。
成果物の引き渡しは人間がファイル添付で行う。

# 成果物
- HTMLファイル1つ。外部ファイル、外部ライブラリ、ネットワーク通信は使わないこと。
- 定石データや評価関数のデータが必要なら、すべてこのファイルの中に埋め込むこと。
- Web Worker は Blob を使ってこのファイル内に書く場合に限り使ってよい。
- コード全文を省略せずに出力すること。

# 対戦の前提
- 人とは対戦しない。石を打つのは常にこのプログラム自身である。
- 相手プログラムとの接点は、下記仕様の棋譜ファイルの読み書きだけである。
- 1手あたりの思考時間に上限はない。

# 画面と機能
1. アプリ名の入力欄を設け、人が記入する。入力されたアプリ名と、プログラムのバージョン（vn.nn 形式、v1.00）を画面に表示する。
2. 盤面を表示し、最後に打たれたマスを強調する。
3. 自分の色（黒＝先手、白＝後手）を人が選べるようにする。
4. 共有ファイルを指定するボタンを付ける。人が用意した空ファイルを showOpenFilePicker で読み書き可能として開く。
5. スタートボタンを付ける。人がアプリ名を記入し、ファイルを指定し、色を選んでスタートを押したら対局を開始する。押すまでファイルには何もしない。
6. 状態表示として、自分の色、現在の状態（開始前・自分の番・相手の番・終局・エラー）、両者のアプリ名と石数を表示する。
7. 棋譜（着手の一覧）を表示する。
8. 終局時は勝者と石数を表示する。
9. エラー時は内容を表示して停止する。黙って続行しないこと。
10. 再試合：終局またはエラーで停止しているときに、人が新しい空ファイルを指定してスタートを押したら、新しい対局を開始する。アプリ名と色もこのとき変更できる。
11. 相手の着手は、ルール上合法かを必ず検証する。
12. 一手にかけてよい制限時間を人間が入力し、その制限時間内に打つこと。アプリは同一のコンピュータ上で実行されるため、自分の手番の最中のみ思考し、
　待っている時にコンピュータの資源を浪費して相手の計算資源を奪ってはならない。適切なメモリ使用量を確保するのは良い。

# 棋譜ファイル仕様（オセロ棋譜形式 v1.00）

## ファイル
- 人が空のテキストファイル（0バイト）を1つ作り、両方のプログラムに同じファイルを指定する。
- 1ファイルで1局とする。
- 文字コードはUTF-8（BOMなし）、改行はLF。どの行も改行で終わる。
- すでに書かれた内容は変えず、末尾に行を足すだけとする。ファイル全体を書き直してもよいが、既存の行は1文字も変えないこと。

## 行の種類（この5種類だけ）
1. 見出し：「OTHELLO v1.00」。ファイルの1行目にだけ書く。
2. 対局者：2行目は「B 先手のアプリ名」、3行目は「W 後手のアプリ名」。この2行は必ず2行目と3行目にだけ置く。
   - アプリ名は入力欄に記入された文字列の前後の空白を除いたもの。1〜30文字で、改行を含まない。
3. 着手：4行目以降に「B f5」のように、色・半角スペース・マスの順に書く。
   - 色は B（黒）か W（白）。
   - マスは列 a〜h（左から右、小文字）と行 1〜8（上から下）で書く。
4. パス：「B pass」または「W pass」。
5. 終局：「END 勝者 黒の石数 白の石数」。
   - 勝者は B・W・D（引き分け）のどれか。例：「END B 36 28」
   - 石数は盤上の石をそのまま数えた数とし、空きマスは誰にも加えない。

## ルール
- 初期配置は d4・e5 が白、d5・e4 が黒。先手は黒。
- 4行目以降の着手行とパス行の色は、必ず B, W, B, W… と交互になる。
- 4行目以降の着手行とパス行の数が偶数なら次は黒番、奇数なら白番。

## 手順
- 開始（黒番）：スタートが押されたら、指定ファイルが空であることを確認し、1行目の見出しと2行目「B 自分のアプリ名」を書く。空でなければ何も書かずにエラーとする。その後、3行目が書かれるのを待ち、書かれたら4行目に黒の初手を書く。
- 開始（白番）：スタートが押されたら、1行目と2行目が書かれるのを待つ。書かれたら3行目「W 自分のアプリ名」を書き、黒の初手を待つ。
- 進行：1秒ごとにファイルを読む。自分の番になったら、思考して1行追記する。
- パス：自分の番で打てる場所がなく、相手には打てる場所があるときは、自分で pass を書く。
- 終局の判断と記録は、必ず黒番（先手）のプログラムが行う。
  - 黒番は、自分が着手行・パス行を書いた直後と、白の行を読んだ直後に、黒も白も打てる場所がないか確認する（盤が埋まった場合も含む）。
  - どちらも打てなければ、黒番が END 行を書く。このときパス行は書かない。
  - 白番は、黒も白も打てる場所がない状態になったら、何も書かずに黒番の END 行を待つ。
  - 白番は END 行を読んだら自分でも石を数えて照合し、一致しなければエラーとする。
- 読み込み：改行で終わっていない最後の行は、書き込み途中とみなして無視し、次に読むときに改めて読む。
- エラー：次のどれかがあれば、不正な棋譜として停止する。
  - 1行目が「OTHELLO v1.00」でない、2行目が「B 」で始まらない、3行目が「W 」で始まらない。
  - 色が交互でない行、打てないマスへの着手、END の後の行、白が書いた END 行。

## 例
OTHELLO v1.00
B AlphaReversi
W DeepOthello
B f5
W d6
B c3
...
W pass
B h8
END B 36 28
