  灰色のまま残るのは ブラックホール・番号シャッフル・テレポートポケット の**3種**。

  ■ 効き目（実測で決めた。付録B送りの3つを確定）
    風速 **200 mm/s**（一度だけ加える速度。★加速度ではない。dt を掛けない）
      … 手玉の止まる場所が 247mm＝玉4.3個ぶん動く。地震（3.2個）・傾き（3.5個）より一段強い
      ★同時に **静止球が 109mm＝玉1.9個ぶん風下へ流される**
        ＝この値は「毎ショット、ラック全体が何mm滑るか」でもある
    玉ごとのばらつき **±55%**
      … 全球きっかり同じだと**ラックが陣形を保ったまま丸ごと滑って不自然**（利用者指摘）
      ★係数はショット開始に共有シードから引き、**引く個数は玉の数によらず16個で固定**
        （残っている玉の数だけ引くと、玉が落ちた局面で乱数列がずれてAIの読みと食い違う）
    方向 **全方位（連続）** … 毎ショットの事故であって、覚えて使う対象ではない
    遅れ **0.3秒**（144刻み）／★上限 0.65秒・★0にはできない

  ■ ★作り方＝「全球へ同時」ではなく「**風の前線が台を横切る**」（利用者指示）
    前線の速さ **24 m/s**（＝100%で撞いた手玉の初速 12 m/s の2倍）
    台の対角 2840mm を **0.118秒**で渡り、風上の玉から順に動き出す
    ★**この速さは見た目の値ではなく「一回限り」を支えている値である。**
      遅いと風下へ走る玉が逃げ続けて一度も受けないか、クッションで戻って二度受ける。
      速ければ隔たりは広がる一方なので、すれ違いは必ず1回きりになる
      （実測：手玉を風下へ全速で撞いた 3,300個ぶんで、二度受けた玉は 0）
    ★「もう吹いたか」の印は持たない。吹く刻みを時計の値で決めれば、
      盤面を進める5本の道のどれでも同じ1刻みで1回だけ吹く

  ■ 見せ方と音（★3つの長さがそろっていなかったのを直した）
    ★実測で **効果 2.1ms ⇔ 絵 669ms ⇔ 音 1,440ms** と 700倍の開きがあった（利用者指摘）。
      効果（一瞬）はそのままにし、**絵と音の2つを 0.75秒へそろえた**。
      そろえるには前線を遅くするしかなく、それは「一回限り」の土台を崩すため。
    縞は**進む向きと直交する帯**。先頭の帯の前縁が、そのまま物理の前線
    帯 320本（一度に画面へ出るのは 28〜71本）／厚み 180〜820mm／白の濃さ 0.6%
    ★**「見せる長さ」を1つ置き、帯の連なる長さはそこから逆算する**（mm で直書きすると
      前線の速さを変えた日に絵だけ古くなって音とずれる）
    ★**消え際の形も音とそろえる**（前の6割は落とさず、後ろ4割で消す）。
      全体をなだらかに薄くすると後半が見えず「音より早く消えた」ように見える
      （実測：出ているのは 750ms なのに、見えているのは 581ms だった）
    ★**本数を増やすときは濃さも下げる**（太い帯は重なるので画面全体が明るくなる。
      2倍にしたら画面に乗る白が 3.5/255 → 9.2/255 になった）
    ★縞のばらつきに乱数を引かない（帯の番号から作る。毎コマ引くと砂嵐に見える）

  ■ 音は素材（効果音ラボ「寒いギャグで突風が吹く」）
    ★合成音では届かなかった。帯を動かすだけでは「さー」にしかならず、
      共鳴を重ねて高さを作っても「ただのノイズ」と指摘を受けた
    **元 97.3KB → 入れる 6.1KB（94%減）**
      素材は「びゅー」が2回入っているので、**1回目の終わり（谷は0.65〜0.78秒）**で消える形に切った。
      モノラル・64kbps。消え際は長さの4割を2乗で落とす（100msでは足りずブツ切れに聞こえた）
    ★**直リンクはしない**（規約で禁止）。複製を assets\se\se-wind-gust.mp3 に置いて鳴らす。
      規約の「直リンク禁止」は**配布元のサーバーに配らせることの禁止**であって、
      複製を自分の側に置くことの禁止ではない（「再配布でないケース例1：アプリに操作音として
      効果音を組み込む（音源ファイルむき出しでも可）」が名指しで許可している）

プログラム v1.92  ⇔  文書 v0.44   2026-09-10
  ★**地震の揺れ方を、利用者の指摘で作り直した**（第57セッションの続き）。指摘は4つ。

  ①「普段の揺れが不自然」→ **常時の揺れを振幅の25%から5%へ**（5分の1）
  ②「静止はせずゆっくり増減を」→ **その値を中心に±50%をゆっくり行き来する**（下限は半分＝0にならない）
     ★割り切れない2つの周期（7.3秒・3.1秒）を重ねて作る。**乱数は引かない**
     （毎回引くとがたつくうえ、5.2.4節が演出用の乱数を禁じている）
  ③「本震の玉の揺らぎを本物に寄せて」→ その場の震えを弱め、位置が変わるほうを強く
  ④★**「玉が台に付いて動いていて、地震の影響を受けて見えない」**

  ★**④が作り方そのものの誤りだった。**
   入れていた「その場で震える」ぶんは**台の揺れと無関係な向き・速さ**だった。
   これでは「台についていっていない」という見え方に**原理的にならない。**
   台の揺れは盤面全体を動かすので、その上で玉が別のリズムで震えても
   **目には「台と一緒に動いている」としか映らない。**

   本物は逆で、**激しく揺れる台の上で玉はすべり、台ほど動かない。**
   → **台の変位そのものに係数を掛けて打ち消す**形へ作り直した。
     **同じ向き・同じ位相の軸で効かせるのが要点。**

  値
   ・すべり **60%**（玉は台の4割しか動かない）。★玉ごとに±35%の差をつける
     （全球同じだと「台の揺れが小さくなっただけ」に見える）
   ・位置のずれ **55%**（数秒かけて別の場所へ移って戻る）。★**75%は全球そろえる**
     （玉ごとに独立して大きく動かすと**ラックの隣どうしが重なって見える**。
       そろえればD54「盤面全体が同じ向きへ押される」とも合う）
   ・常時を弱めたので止まる場所のずれを測り直した＝**185mm＝玉3.2個ぶん**
     （氷と重ねたときの安全弁は 3/104 → 1/105 へ減った）

  検査は全20本 ok 1542 / NG 0 / 赤0本（check_field.js は 127 → 136 件）。
  壊し確認22通りすべてで狙った検査が赤くなることを確かめた。
  ★**そのうち2件は空振りだった**ので線を引き直した。
   ・「そろって動く」の線が 0.75 では、そろえるのをやめても 0.67 で素通り → **0.5** へ
   ・「位置がずれる」を**振れ幅**で見ていたが、すべりだけでも往復するので振れ幅は出る
     → **1秒ごとの平均の位置**で見る形へ（正しい実装 17.5mm ⇔ 消すと 0.1mm）

プログラム v1.89  ⇔  文書 v0.43   2026-09-09
  ★**異常モードの2つめ＝地震（F-01）を入れた**（第57セッション）。

  ★**やっていることは1つだけ＝転がっている玉へ、揺れの向きの行ったり来たりする加速度を足す。**
   向きも位相も全球で共通なので、盤面全体が同じ瞬間に同じ側へ押される。
   静止球にも空中の玉にも足さない（傾きとまったく同じ条件）。

  ★**傾きのときの心配（強くすると玉が止まらない）は、地震には当てはまらない。**
   傾きは向きが一定なので氷の上で加速し続けたが、**地震は半周期ごとに押し返す。**
   実測でも安全弁の働く割合は地震なしとほぼ変わらない。**だから強さは効き目だけで決めてよい。**

  値（付録B送りを実測で確定・D453）
   ・振幅 1500 mm/s^2 ＝ 止まる場所が 195mm（玉3.4個ぶん）動く。利用者判断＝「傾きと同じくらい」
   ・2Hz ★**効き目は振幅÷振動数だけで決まる**ので、振動数は見え方を決める値。動かすときは振幅も動かす
   ・時定数2秒で弱まるが、**0にはならず振幅の25%（常時の揺れ）で下げ止まる**（利用者判断）
     ＝地震は撞いた瞬間だけの出来事ではなく、鳴り続けている状況である
   ・方向は全方位（傾きの8方位と逆。地震は覚えて使う対象ではない）
   ・揺れ始めはショット開始。位相を毎回引き直すと押しと押し返しが相殺して向きへ偏らなくなる

  ★**ショットの時計を engine が持つようにした**（D454）。全球停止で0に戻す。
   ゲーム内時間はゲーム開始から増え続けるので、ショット開始を起点にする位相を作れない。
   **呼ぶ側に「ショットが始まった」と教えてもらう形にすると、盤面を進める5本の道のどれかで必ず書き忘れる。**

  見せ方（D455・利用者判断）
   ・画面の揺れは**6倍**にして見せる。物理どおりでは台は ±9.5mm しか動かず地震だと分からない
     （実測の縮尺 0.2168 px/mm ＝ 常時 6.2px・撞いた瞬間 24.7px）
   ・玉ひとつひとつも台の揺れ幅の35%だけ震わせる
   ・★**ぶれは描くときだけ足し、玉の座標は変えない。**座標へ足すと積み上がって静止球が流れ、全球停止が壊れる
   ・★**ぶれに乱数を引かない**（玉の番号から作る）。毎コマ引くと玉が痙攣して見える
   ・★**画面の位相は実時間で回す。**盤面の時計は撞いていない間止まるので、狙っている最中に画面が凍る
   ・3Dは構える段でしか描かれないので、3Dで見えるのは常時の揺れのほう
