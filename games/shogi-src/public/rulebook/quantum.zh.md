# MOMO Shogi式量子将棋（以下简称“Quantum Shogi”）规则手册

Version 1.0

---

# 前言

Quantum Shogi（量子将棋）是一种以传统将棋为基础的策略棋类游戏。

它与传统将棋最大的不同在于：**棋子的身份在游戏开始时并不是确定的。**

随着游戏进行，每枚棋子的真实身份会逐渐明确。

玩家不仅需要推理对手棋子的身份，也需要推理自己棋子的身份。

---

# 什么是 Quantum Shogi？

在 Quantum Shogi 中，每一枚棋子都拥有一个**候选集合（Candidate Set）**。

例如，一枚棋子的候选可能是：

- 王
- 金将
- 银将

此时，这枚棋子的真实身份尚未确定。

随着游戏进行，候选会不断减少。

当候选只剩下一种时，这枚棋子的身份便被确定。

---

# 游戏特点

Quantum Shogi 具有以下特点：

- 所有信息完全公开。
- 没有任何随机因素。
- 候选只会减少，不会增加。
- 棋子的身份通过逻辑推理逐步确定。
- 与传统将棋一样，需要进行棋局计算与战略思考。

---

# 游戏目标

**将死对方已经确定为“王”的棋子即可获胜。**

吃掉已经确定的王也会获胜。例如，王在被确定的那一刻，已经处于会被对方吃掉的位置时，就会发生这种情况。

如果吃掉的只是“王候选”，游戏不会结束。

吃掉已经确定的王时，游戏立即结束。

---

# 游戏准备

游戏开始时：

- 按照初始布局摆放棋子。
- 每枚棋子拥有自己的候选集合。游戏开始时，每枚棋子的候选都包括王、飞车、角行、金将、银将、桂马、香车、步兵全部八种。
- 先手首先行动。

---

# 棋子

游戏使用与传统将棋相同的棋子种类和数量。

包括：

- 王
- 飞车
- 角行
- 金将
- 银将
- 桂马
- 香车
- 步兵

但是，在游戏开始时，每枚棋子的真实身份尚未确定。

---

# 候选集合

候选表示：

**这枚棋子有可能是什么棋子。**

例如：

```
步兵 / 银将 / 金将
```

表示它可能是：

- 步兵
- 银将
- 金将

但此时尚未确定。

---

# 候选减少

游戏过程中，候选会因为以下情况而减少：

- 棋子移动
- 棋子被吃
- 其他棋子身份确定

例如：

```
步兵 / 银将 / 金将

↓

不可能是步兵

↓

银将 / 金将

↓

不可能是银将

↓

金将
```

当只剩下一种候选时，该棋子的身份即被确定。

---

# 棋子的移动

棋子可以按照自己当前候选所允许的合法走法移动。

随着候选减少，可移动的方式也可能发生变化。

---

# 回合

双方轮流行动。

每个回合可以进行以下一种操作：

- 移动一枚棋子
- 打入一枚持驹

---

# 吃子

移动到对方棋子所在的位置即可吃掉该棋子。

被吃掉的棋子成为自己的持驹。

---

# 持驹

持驹可以在自己的回合重新打入棋盘。

打入位置必须符合传统将棋的限制。

拥有多个候选的棋子，只要其中任意一个候选可以打入该位置，就可以打入。打入后，不能存在于该位置的候选会被排除。

---

# 升变

可以升变的棋子与传统将棋相同。

当满足升变条件时，可以选择：

- 升变
- 不升变

部分情况下必须升变。

拥有多个候选的棋子升变时，不能升变的候选（王、金将）会被排除。不升变时，不升变就不能停留在该位置的候选会被排除。

---

# 王

每位玩家都拥有一枚王。

但是游戏开始时，并不知道哪一枚棋子是真正的王。

当某枚棋子的候选集合只剩下"王"时，它便成为确定的王。

---

# 王手

如果已经确定的王将在下一步被合法吃掉，则称为王手。

尚未确定的王候选不会形成王手。

---

# 将死

如果王手无法通过任何合法着法解除，则形成将死。

将死时，游戏立即结束。

---

# 胜负

**将死对方已经确定的王即可获胜。**

吃掉已经确定的王也会获胜。例如，王在被确定的那一刻，已经处于会被对方吃掉的位置时，就会发生这种情况。

吃掉王候选不会结束游戏。

---

# 二步

同一方不能在同一纵线上拥有两枚未升变的步兵。

---

# 打步将死

不能通过打入步兵立即形成将死。

打入后因此被确定为步兵的棋子也同样适用。打入拥有多个候选的棋子并形成将死时，视为该棋子不是步兵，并排除其步兵候选。

---

# 千日手

相同局面出现四次时，形成千日手。

局面包括：

- 棋子位置
- 候选集合
- 升变状态
- 持驹
- 当前行棋方

---

# 入玉宣言与持将棋

入玉宣言和持将棋与传统将棋相同。但是，由于棋子的身份可能尚未确定，需要按以下方式理解：

- 只有当所有仍以王为候选的棋子都位于敌阵之内，并且都不在对方棋子的攻击范围内时，才视为已经入玉。
- 计算点数时，只有候选全部为大驹（飞车、角行、龙王、龙马）的棋子计5分，其余棋子计1分，然后从总分中减去王的1分。

---

# 游戏流程

游戏按照以下顺序进行：

```
游戏开始

↓

开始回合

↓

选择合法着法

↓

执行着法

↓

（是否吃掉已确定的王？）

是

↓

游戏结束

否

↓

吃子处理

↓

升变判定

↓

候选更新

↓

候选确定与传播

↓

胜负判定

↓

若游戏未结束

交换行棋方
```

# 候选如何传播

在 Quantum Shogi 中，当一枚棋子的身份被确定后，属于同一初始阵营的其他棋子的候选集合也可能会随之连续更新。

这是因为每种棋子的数量都是固定的，就像传统将棋一样。

例如，每位玩家最初只有 **两枚金将**。

当这两枚金将都已经确定后，属于该玩家初始阵营的其他棋子就不可能再是金将。

这种由一个确定的信息自动影响其他棋子的过程，称为“**候选传播**”，本游戏将候选的传播称为“**量子纠缠**”。

---

## 示例1：在同一初始阵营中的传播

假设某位玩家的棋子具有如下候选集合：

```
棋子A　金将 / 银将
棋子B　金将 / 桂马
棋子C　金将 / 步兵
棋子D　金将（已确定）
```

其中，棋子D已经确定为金将。

由于该玩家最初只有 **两枚金将**，

因此，棋子A、B、C之中只有 **一枚** 可能是另一枚金将。

随后，游戏过程中确定：

```
棋子A = 金将
```

此时，该玩家的两枚金将已经全部确定：

- 棋子A
- 棋子D

因此，棋子B和棋子C不可能再是金将。

它们的候选集合变为：

```
棋子B　桂马
棋子C　步兵
```

于是，这两枚棋子的身份也随之确定。

这说明，一枚棋子的确定，可能立即使其他多枚棋子同时确定。

---

## 示例2：传播到对方控制的棋子

候选不仅会传播到自己当前控制的棋子。

它同样会影响已经被对方吃掉、目前由对方控制，但**最初属于自己阵营**的棋子。

例如：

```
自己初始阵营的棋子

棋子A　金将 / 银将
棋子D　金将（已确定）

属于自己初始阵营，
但目前由对方控制的棋子

棋子C　金将 / 步兵
```

此时，

棋子A与棋子C之中，只有一枚可能是第二枚金将。

后来，

```
棋子A = 金将
```

被确定。

于是，该玩家最初拥有的两枚金将已经全部确定为：

- 棋子A
- 棋子D

因此，

```
棋子C = 步兵
```

虽然棋子C目前由对方控制，它的候选集合仍然必须更新。

---

## 被吃掉的棋子仍然属于原来的阵营

在 Quantum Shogi 中，

棋子被吃掉后，**控制者会改变，但初始所属阵营不会改变。**

候选传播始终以棋子的**初始所属阵营**为依据，而不是当前控制者。

因此，候选会传播到：

- 自己盘上的棋子
- 自己的持驹
- 对方盘上原本属于自己的棋子
- 对方持有、原本属于自己的棋子

由于每枚棋子始终保留自己的初始所属，因此，只要获得新的信息，它就可能传播到整个棋局。

因此，一枚棋子的确定，可能会引发连续的候选更新，并最终使许多棋子的身份依次确定。

# 二步规则对候选集合的影响

在 Quantum Shogi 中，与传统将棋一样，禁止出现**二步**。

此外，每位玩家在游戏开始时都拥有 **9 枚步兵**。

因此，在初始布局中，**每一路（纵列）都必须存在且仅存在一枚属于该玩家初始阵营的步兵。**

这一规则不仅限制着法，也会影响棋子的候选集合。

例如，假设初始位于第一路的两枚棋子具有如下候选：

```
第一路

棋子A　步兵 / 银将
棋子B　步兵 / 桂马
```

随后，游戏过程中棋子A被确定为银将。

```
棋子A = 银将
```

由于第一路必须存在一枚步兵，因此棋子B只能是步兵。

```
棋子B = 步兵
```

反过来，如果棋子A被确定为步兵，

```
棋子A = 步兵
```

那么棋子B就不可能再是步兵。

```
棋子B = 桂马
```

因此，二步规则不仅用于判断非法着法，

**“初始布局中每一路都必须有一枚步兵”**这一事实，同样能够用于缩小候选集合，并帮助确定棋子的身份。

---

# 打入持驹时的二步规则

二步规则同样适用于打入持驹。

例如，第五路已经存在一枚确定为步兵的棋子。

```
第五路

盘上棋子　步兵（已确定）
```

此时，玩家将一枚候选集合为

```
步兵 / 银将
```

的持驹打入第五路。

如果该棋子是步兵，就会形成二步，因此这是不允许的。

于是，步兵候选会被移除。

```
步兵 / 银将

↓

银将
```

该棋子立即被确定为银将。

由此可见，**持驹打入的位置，也可能改变棋子的候选集合。**

---

# 王候选如何被排除

每位玩家只有一枚王。

**吃掉已经确定为王的棋子**时，游戏在那一刻结束。

因此，当吃掉一枚仅仅包含王候选的棋子时，游戏不会结束。

例如，对方的一枚棋子具有如下候选：

```
王 / 金将 / 银将
```

当这枚棋子被吃掉后，

游戏仍然继续进行。

既然游戏没有结束，就说明被吃掉的棋子不可能是真正的王。

因此，它的王候选会被移除。

```
王 / 金将 / 银将

↓

金将 / 银将
```

也就是说，

**“游戏仍然继续”这一事实，本身也是一种新的信息，可以用于更新候选集合。**

---

# 一种特殊但重要的战略：夺走对方的飞车

在 Quantum Shogi 中，

即使棋子被吃掉，它仍然保留自己**初始所属阵营**的候选集合。

因此，通过确定一枚已经吃掉的棋子的身份，也可能影响对方仍然留在棋盘上的棋子。

例如，你吃掉了一枚仍然具有飞车候选的对方棋子。

之后，你将这枚棋子重新打入自己的阵地。

如果随后让它执行**只有飞车才能完成的合法移动**，例如横向连续移动两格以上，

那么这枚棋子便立即确定为飞车。

一旦如此，

对方初始阵营中的飞车便已经全部确定。

因此，

**所有仍然属于对方初始阵营的棋子，都必须移除飞车候选。**

换句话说，

你不仅吃掉了对方的一枚棋子，

还使对方剩余所有棋子都失去了成为飞车的可能性。

为了避免这种情况，

对方通常需要尽早将自己初始阵营中的另一枚棋子确定为飞车。

这样，即使你控制着被吃掉的那枚棋子，它也不可能再成为对方的第二枚飞车。

因此，在 Quantum Shogi 中，

玩家不仅需要考虑如何确定自己的棋子，

还需要考虑**自己所捕获的棋子，将来可能对对方的候选集合产生怎样的影响。**

# 常见问题

## 与传统将棋最大的区别是什么？

棋子的身份在游戏开始时并不确定。

---

## 候选会增加吗？

不会。

候选只会减少。

---

## 是否存在隐藏信息？

没有。

所有信息都对双方公开。

---

## 是否有运气成分？

没有。

所有结果都由规则和当前局面决定。

---

## 吃掉王候选会获胜吗？

不会。

只有已经确定的王才与胜负有关。
