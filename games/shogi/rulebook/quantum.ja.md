# MOMO Shogi式量子将棋(以下Quantum Shogi) ルールブック

Version 1.0

---

# はじめに

Quantum Shogi は、将棋をベースにした思考ゲームです。

普通の将棋との最大の違いは、**駒の種類が最初は決まっていない**ことです。

ゲームが進むにつれて、駒は少しずつ正体が判明していきます。

相手の駒だけでなく、自分の駒についても推理しながら戦う、新しいタイプの将棋です。

---

# Quantum Shogiとは

Quantum Shogiでは、すべての駒が「候補」を持っています。

例えば、ある駒は

- 王
- 金
- 銀

という候補を持っているかもしれません。

この時点では、その駒が何であるかはまだ決まっていません。

ゲーム中の行動によって候補が減り、最終的に1種類だけになると、その駒の正体が確定します。

---

# このゲームの特徴

Quantum Shogiには次の特徴があります。

- すべての情報が公開されている
- ランダム要素がない
- 候補は増えず、減るだけ
- 推理によって駒の正体が分かる
- 普通の将棋と同じように盤面を読む力も必要

---

# ゲームの目的

相手の**王として確定した駒**を詰ませると勝利です。

王として確定した駒を捕獲した場合も勝利です。王が確定した瞬間に取られる位置にあった場合などに起こります。

王候補では勝利になりません。

王と確定した駒を捕獲した瞬間にゲームは終了します。

---

# ゲームの準備

ゲーム開始時には、

- 駒を初期配置に並べます。
- 各駒は候補集合を持っています。ゲーム開始時は、どの駒も王・飛・角・金・銀・桂・香・歩のすべてを候補に持っています。
- 先手からゲームを開始します。

---

# 駒について

盤上には通常将棋と同じ種類・枚数の駒があります。

- 王
- 飛
- 角
- 金
- 銀
- 桂
- 香
- 歩

ただし、ゲーム開始時点では、それぞれの駒が何であるかはまだ確定していません。

---

# 候補とは

候補とは、

「この駒は、この駒種である可能性がある」

という情報です。

例

```
歩・銀・金
```

この場合、

歩かもしれないし、

銀かもしれないし、

金かもしれません。

まだ決まっていません。

---

# 候補が減る

ゲーム中、

- 駒を動かす
- 駒を捕獲する
- 他の駒が確定する

などによって候補が減っていきます。

例

```
歩・銀・金

↓

歩では動けない

↓

銀・金

↓

銀でも動けない

↓

金
```

最後に1種類だけ残ると、その駒は確定します。

---

# 駒の動かし方

駒は、

現在持っている候補の範囲で合法となる動きができます。

ゲームが進み候補が減ると、

動ける範囲も変化します。

---

# 手番

先手と後手が交互に指します。

自分の手番では、

次のどちらかを行います。

- 駒を動かす
- 持ち駒を打つ

---

# 捕獲

相手の駒がある場所へ移動すると、その駒を捕獲できます。

捕獲した駒は自分の持ち駒になります。

---

# 持ち駒

持ち駒は、

自分の手番で盤上へ打つことができます。

打てる場所は通常将棋と同じ制限があります。

候補が複数ある駒は、候補のどれか1つでもそこに打てれば打つことができます。打った後、そこに置けない候補は取り除かれます。

---

# 成り

成ることができる駒は通常将棋と同じです。

成れる場面では、

- 成る
- 成らない

を選択できます。

強制的に成らなければならない場合もあります。

候補が複数ある駒が成った場合、成ることのできない候補（王・金）は取り除かれます。成らなかった場合、成らないとそこに置けない候補は取り除かれます。

---

# 王

各プレイヤーには王が1枚存在します。

ただし、

ゲーム開始時には王がどの駒なのかは分かりません。

候補が減って王だけになったとき、その駒は王として確定します。

---

# 王手

王として確定した駒が、

次の相手の手で捕獲される状態を王手といいます。

王候補には王手は成立しません。

---

# 詰み

王手を解除する合法手が存在しない状態を詰みといいます。

詰みになるとゲームは終了します。

---

# 勝敗

相手の王として確定した駒を詰ませると勝ちです。

王として確定した駒を捕獲した場合も勝ちです。王が確定した瞬間に取られる位置にあった場合などに起こります。

王候補を捕獲しても勝利にはなりません。

---

# 二歩

同じプレイヤーの成っていない歩を、

同じ筋に2枚存在させることはできません。

---

# 打ち歩詰め

歩を打って、その一手で詰みにすることはできません。

打った結果、歩と確定する駒を打つ場合も含みます。候補が複数ある駒を打って詰みにした場合は、その駒は歩ではなかったことになり、歩の候補が取り除かれます。

---

# 千日手

同じ局面が4回繰り返されると千日手になります。

局面には、

- 駒の位置
- 候補
- 成り状態
- 持ち駒
- 手番

などが含まれます。

---

# 入玉宣言・持将棋

入玉宣言と持将棋は通常の将棋と同じです。ただし、駒の正体が決まっていないため、次のように読み替えます。

- 入玉できているとみなすのは、王の候補を持つ駒がすべて敵陣にあり、どれも相手の駒の利きの中にないときです。
- 点数は、候補がすべて大駒（飛・角・龍・馬）の駒だけを5点、それ以外を1点として数え、合計から王の分として1を引きます。

---

# ゲームの流れ

ゲームは次の順番で進みます。

```
ゲーム開始

↓

手番開始

↓

合法手を選ぶ

↓

着手

↓

（王を捕獲した）
    ↓
ゲーム終了

（王を捕獲していない）
    ↓

捕獲処理

↓

成り判定

↓

候補更新

↓

候補の確定・伝搬

↓

勝敗判定

↓

終了していなければ手番交代
```

---

# 候補はどのように確定していくのか

Quantum Shogiでは、一枚の駒が確定すると、同じ初期陣営に属する他の駒の候補も連鎖的に更新されます。

これは、将棋では各駒の枚数が決まっているためです。

例えば、金将は各プレイヤーが2枚ずつしか持っていません。

もし2枚とも金将であることが分かれば、それ以外の駒は金将ではありません。

このように、一つの情報が別の駒へ影響していくことを「**候補が伝搬する**」といい、候補が伝搬することを本ゲームでは「**量子もつれ**」と呼びます。

---

## 例1　同じ陣営への伝搬

あるプレイヤーの駒が次のような候補を持っているとします。

```
駒A　金・銀
駒B　金・桂
駒C　金・歩
駒D　金（確定）
```

すでに駒Dは金将と確定しています。

金将は2枚しか存在しないため、

駒A・B・Cの中に金将は1枚だけ存在することになります。

その後、ゲームが進み、

```
駒A = 金
```

と確定しました。

すると、そのプレイヤーの2枚の金将がすべて判明したことになります。

その結果、

```
駒B　桂
駒C　歩
```

となり、駒Bと駒Cも確定します。

このように、一枚の確定が別の駒の確定につながることがあります。

---

## 例2　相手の駒にも伝搬する

候補が伝搬するのは、自分の駒だけではありません。

相手が持っている自分の元の駒にも影響します。

例えば、

```
自分の駒

駒A　金・銀
駒D　金（確定）

相手が捕獲している自分の駒

駒C　金・歩
```

この状態では、

駒Aと駒Cのどちらか一方だけが金将です。

その後、

```
駒A = 金
```

と確定すると、

自分の2枚の金将は

- 駒A
- 駒D

であることが確定します。

すると、相手が持っている駒Cは金将ではありえません。

その結果、

```
駒C = 歩
```

と確定します。

つまり、**相手が持っている駒であっても、その駒の候補は更新されます。**

---

## 捕獲されても情報は失われない

Quantum Shogiでは、駒が捕獲されても、その駒が最初にどちらのプレイヤーの駒であったかは変わりません。

そのため、候補は、

- 自分の盤上の駒
- 自分の持ち駒
- 相手の盤上にある自分の元の駒
- 相手の持ち駒になっている自分の元の駒

のすべてに伝搬します。

駒の現在の所有者ではなく、**その駒が最初にどちらのプレイヤーに属していたか**を基準として候補が管理されるためです。

この仕組みにより、ゲーム中のあらゆる情報が盤面全体に伝わり、一つの確定が思わぬ場所の駒を確定させることがあります。

# 二歩が候補に与える影響

Quantum Shogiでは、通常将棋と同様に二歩は禁止されています。

また、各プレイヤーは初期状態で9枚の歩を持っています。

そのため、初期配置では**各筋に必ず1枚ずつ歩が存在する**ことになります。

この制約は、ゲーム中の候補にも影響します。

例えば、ある筋に初期配置された2枚の駒が

```
1筋

駒A　歩・銀
駒B　歩・桂
```

という候補を持っていたとします。

その後、駒Aが銀と確定すると、

```
駒A = 銀
```

となります。

1筋には必ず歩が1枚存在しなければならないため、

```
駒B = 歩
```

と確定します。

逆に、

```
駒A = 歩
```

と確定した場合は、

```
駒B = 桂
```

となります。

このように、二歩の禁止だけでなく、「各筋に必ず歩が1枚存在する」という条件も、候補を確定させる重要な情報になります。

---

# 持ち駒を打ったときの二歩

二歩の制約は、持ち駒を打った場合にも適用されます。

例えば、5筋に歩がすでに確定しているとします。

```
5筋

盤上の駒　歩（確定）
```

ここで、

```
持ち駒

歩・銀
```

という候補を持つ駒を5筋へ打った場合、

その駒が歩であると二歩になってしまいます。

二歩は禁止されているため、

```
歩・銀

↓

銀
```

となり、その駒は銀と確定します。

このように、持ち駒を打つ位置によっても候補が変化することがあります。

---

# 王の候補が減る場合

王は各プレイヤーに1枚しか存在しません。

王として確定した駒を捕獲すると、その時点でゲームは終了します。

そのため、王候補を持つ駒を捕獲しても、ゲームは終了しません。

例えば、

```
相手の駒

王・金・銀
```

という候補を持つ駒を捕獲したとします。

ゲームが終了しなかったということは、

その駒は王ではありません。

したがって、

```
王・金・銀

↓

金・銀
```

となり、王の候補は取り除かれます。

このように、「ゲームが継続した」という事実も、新しい情報として候補更新に利用されます。

---

# 相手の飛車を「奪う」戦略

Quantum Shogiでは、相手から捕獲した駒も、その駒が最初に属していたプレイヤーの候補集合を保持しています。

そのため、相手の駒を自分が使用して確定させることで、相手陣営全体の候補にも影響を与えることがあります。

例えば、相手の飛車候補を含む駒を捕獲したとします。

その駒を自陣へ打ち直し、

飛車にしかできない動き（例えば横方向へ2マス以上移動）を行うと、その駒は飛車として確定します。

すると、相手が最初に持っていた飛車はすべて判明したことになるため、

相手陣営に残っているすべての駒から飛車の候補が取り除かれます。

この戦略は、相手の飛車を盤上から奪うだけでなく、相手がまだ正体を隠していた飛車の候補まで消してしまう効果があります。

逆に、この状況を防ぐためには、相手より先に自分の飛車を確定させることも重要になります。

このように、自分の駒を確定させるだけでなく、**相手の初期所属の駒を確定させることも戦略の一つ**となります。

# よくある質問

## 普通の将棋との違いは？

駒の正体が最初から決まっていないことです。

---

## 候補は増えますか？

増えません。

減るだけです。

---

## 情報は隠されていますか？

いいえ。

すべての情報は両プレイヤーに公開されています。

---

## 運の要素はありますか？

ありません。

すべての結果はルールと局面から決まります。

---

## 王候補を捕獲したら勝ちですか？

いいえ。

王として確定した駒だけが勝敗の対象になります。
