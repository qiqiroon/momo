# MOMO Remaster - audio restoration and remastering
- **概要**: カセットテープやレコードから取り込んだ音声を、ブラウザの中だけで整えて書き出すツールです。区間の切り出し・削除・分割・挿入、DC オフセット除去・ハイパス／ローパス・パラメトリック EQ・ゲイン・全体フェード、処理前後の聴き比べ（A/B）ができ、WAV・FLAC・ALAC・MP3・AAC・Ogg Vorbis・Opus で書き出せます。
- **使い方**: パソコンの Google Chrome または Microsoft Edge（最新版）で開き、音声ファイルを『開く』で選ぶか、画面へドラッグしてください。音声はお使いの端末の中で処理され、外へ送られません。
- **既知の制約（現在の版）**:
  - ページを再読み込みしたり閉じたりすると、編集の内容は失われます（プロジェクトの保存は今後の版で加えます）。
  - 起動するたびに、前回までに読み込んだ音声の作業用のデータをブラウザの保存領域から消します。書き出したファイルは消えません。
- **クレジット**: 使っているソフトウェア（FFmpeg・LAME ほか）と書体の著作権表示・ライセンス・ソースの入手方法は、アプリの『設定』→『クレジット』にあります。
